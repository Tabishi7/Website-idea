# Website ideas

A notebook for every idea about the website: betterment, new pages, promotions, design, and anything else.

The reading file is **[IDEAS.md](IDEAS.md)**. Open it, add a line, commit, and push.

**When you resume work, follow [priority order](IDEAS.md#priority-order):**

1. Owner email after a purchase (user summary + delivery / download / attachment status)
2. Sign-off interview section (around 100 questions)

## How to add an idea

1. Edit `IDEAS.md`
2. Put the idea at the top of **Inbox** (or the section it belongs in)
3. Save, commit, and push to this repo

You do not need a perfect sentence. Date it in **Log** if you want a record of when it showed up.

## Sections in the reading file

| Section | Use it for |
| --- | --- |
| Priority order | What to build first, then second |
| About the website | Name, URL, purpose, who it is for |
| Inbox | Quick dump before you sort |
| Betterment | Improve what already exists |
| New pages and features | Things the site does not have yet |
| Promotions and growth | Marketing, launches, reach |
| Design and writing | Look, tone, copy |
| Questions | Open decisions |
| Log | Dated notes |
